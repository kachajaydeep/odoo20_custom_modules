Pos Close Session From Backend

The Pos Close Session From Backend module allows seamless management of Point of Sale (POS) sessions directly from the Odoo backend. Users can open, track, and close POS sessions without remaining in the POS frontend, making session management faster and more efficient. It provides real-time visibility of orders and session statuses, supports multiple simultaneous sessions, and ensures accurate cash handling by matching the Ending Balance with the Expected Balance.

User Report Flow

Add the desired products to the order and then click Payment to continue with the payment process.

Select the Cash payment method and click the Validate button to confirm the order.

Click the New Order button.

Now navigate to the Odoo backend by clicking the Backend menu.

From Orders, click on the session to access its details.

Navigate to the POS session that is currently in the In Progress status.

Press the Close POS Session button to complete the POS session closure.

Set the Ending Balance to match the Expected Balance, then click the Close Session button.

Once the session is closed, check the session status and confirm the Ending Balance matches the entered value. Navigate back to the Point of Sale by clicking Point of Sale.
