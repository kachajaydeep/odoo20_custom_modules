Name Shortcut Key Action
Back Action ← Return to the previous screen.
Product Screen F1 Open the product screen.
Payment Screen F2 Navigate to the payment screen for checkout.
Orders Screen F3 View and manage open and completed orders.
Next Order Shift + ↓ Switch to the next active order.
Previous Order Shift + ↑ Switch to the previous active order.
Next Order Line Ctrl + ↓ Move the selection to the next order line.
Previous Order Line Ctrl + ↑ Move the selection to the previous order line.
Focus Search Bar Ctrl + F Place the cursor in the product search field.
Clear Search Ctrl + D Clear the current search text and reset the product list.
Numpad Quantity Q Switch the numpad to Quantity mode.
Numpad Discount D Switch the numpad to Discount mode.
Numpad Price P Switch the numpad to Price mode.
Action Button Shift + A Open the Actions menu.
Validate Order Shift + V Validate the current order.
Add Cash Payment Alt + C Add a cash payment to the current order.
Add Card Payment Alt + O Add a card payment to the current order.
Add Customer Account Payment Alt + A Add payment using the customer's account balance.
Validate Payment Shift + Enter Confirm the payment and complete the order.
Show Shortcuts F4 Display the keyboard shortcuts reference.

⚙ Configuration

Keyboard Shortcuts : Enable Keyboard Shortcuts

⌨ POS Keyboard Shortcuts Workflow

Point Of Sale → Click "Open Register"

Press F4 and open keyboard shortcuts

Press Q and move the Quantity button

Press D and move the Discount button

Press P and move the Price button

Press SHIFT + A and open Action View.

Press Ctrl + F and Search Product.

Press Ctrl + C and Customer Menu Open.

Press F2 and Payment Screen.

Press Shift + Enter and Payment Validate.
