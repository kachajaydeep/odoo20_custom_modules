🛒 Create Purchase Order from POS workflow

APPS → Create Purchase Order from POS | Odoo POS Purchase Integration → Activate

Purchase Order Configuration in POS :Point Of Sale → Configuration → Settings
1. Enable the Purchase Order option in the POS settings.
2. Select the Purchase Order state (RFQ, RFQ Sent, or Purchase Order).
3. Additionally, users can enable the Auto Validate Receipt and Create Vendor Bill options.

Go to Point of Sale → Dashboard → Open Register/Continue Selling

Create a POS order, add an order line, and click the "Actions" button.

Click the "Create RFQ/PO" button.

Select a vendor and click the "Create" button.

View the notification for the created Purchase Order. The cashier can also print the Purchase Order from the POS screen.

View the printed RFQ/PO.

Users can view all created Purchase Orders directly from the Point of Sale menu.

Purchase management can see who created the Purchase Order and from which POS session it was created during the day.

The Purchase Receipt is automatically validated.

The Purchase Bill is also created automatically.

Additionally, filters and Group By options have been added to the Purchase Order list view for filtering orders.
