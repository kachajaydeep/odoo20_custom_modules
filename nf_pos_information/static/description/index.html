How does the Product Information Popup work?? +

The module adds an information button below each product card in the Odoo POS screen. Clicking the button instantly opens a popup displaying detailed product information including image, price, category, barcode, type, and description.

Does the popup affect POS performance? +

No, the popup is optimized for fast loading and smooth interaction, ensuring a seamless checkout experience without interrupting ongoing sales operations.

Is the module responsive on different screen sizes? +

Yes, the popup interface is fully responsive and works properly on desktop screens, POS terminals, and touch-enabled devices.

Is any technical configuration required after installation? +

No, complex configuration is required. Simply install the module and the product information button will be available in the POS product cards.
