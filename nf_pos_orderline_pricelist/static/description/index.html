Odoo Module · Point Of Sale Orderline Pricelist

Point Of Sale
Orderline Pricelist

Enhance and control product-wise pricelist management directly from the Odoo POS interface with dynamic pricelist selection for each individual product. This module allows cashiers to apply different pricelists product-by-product directly from the product card using an interactive popup selection system .
This module enhances the Odoo POS by adding a dedicated pricelist button below each product price section, allowing users to open a popup and apply different pricelists individually for each product. Once selected, the system automatically calculates the discounted price and displays the applied pricelist name, original price with line-through formatting, and final discounted price in bold. The same pricing details are also shown on the POS receipt for better transparency. On the backend, the selected pricelist information is stored for each order line with proper tracking support.
