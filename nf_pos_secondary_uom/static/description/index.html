Point Of Sale Secondary UoM

Point of Sale Secondary UoM allows your sales staff to sell products using a Secondary Unit of Measure directly from the Odoo Point of Sale.
This module makes the selling process quick and accurate by allowing users to choose the appropriate secondary unit without manually calculating quantities.

Everything you need to know in one video

Manage products with a secondary unit of measure directly in Odoo Point of Sale. Sell products using primary and secondary UoM, improve billing accuracy, and simplify retail operations with automatic quantity conversion.

The module introduces a simple and intuitive workflow where cashiers can select the desired selling unit, enter the quantity, and complete the sale without performing any manual calculations. Based on the configured conversion ratio, the system automatically converts the entered quantity into the product's primary inventory unit, calculates the correct selling price, and deducts the appropriate stock. This ensures accurate inventory management while providing a faster and more efficient checkout experience.

What does this module do? +

This module allows you to sell products using a Secondary Unit of Measure (UoM) directly from the Odoo Point of Sale. It automatically converts quantities, calculates prices, and updates inventory based on the configured conversion ratio.

Can I sell a product using both Primary and Secondary UoM? +

Yes, You can sell products using either the primary inventory unit or a configured secondary unit directly from the POS.

What is the Default UoM feature? +

The Default UoM feature automatically selects a predefined Unit of Measure when a product is added to a POS order, reducing manual clicks and speeding up the checkout process.

Can the cashier change the default UoM? +

Yes, Even if a default UoM is configured, the cashier can easily switch to another available Unit of Measure before completing the sale.

Does the module calculate prices automatically? +

Yes, Prices are calculated automatically based on the selected Unit of Measure and the entered quantity.
