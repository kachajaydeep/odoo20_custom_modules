Create Sale Order From Point of Sale

Create Sale Order From Point of Sale enhances the Odoo Point of Sale by allowing users to instantly generate Quotations or Sale Orders directly from the POS interface.
Instead of manually recreating customer orders in the Sales module, users can convert POS orders into Quotations or confirmed Sale Orders with a single click. This saves time, reduces manual work, and improves business efficiency.
The module also supports adding Sections in POS Orders, Quotations, and Sale Orders for better organization. These section lines are transferred automatically and can even be displayed on the POS receipt.

✔ One-Click Order Creation

Users can create either a Quotation or a Sale Order from the current POS order.

✔ Print Sale Order

Print the created Sale Order directly from the confirmation popup.
