Product Sale Report | Sales & POS Product Sales Analysis

Product Sale Report helps businesses analyze product-wise sales from both Sales Orders and Point of Sale (POS) within a selected date range. Generate detailed product sales reports by filtering products based on categories and choosing the report source (Sales, POS, or Both).
The module adds a dedicated Product Sales Report under the Reporting menu, making it easy to monitor product performance and download reports whenever needed.

✔ Unified Sales & POS Product Reporting

Generate a single product sales report using Sales Orders, Point of Sale Orders, or both for complete business insights.

✔ Flexible Date Range Filters

Analyze product sales for any period using Start Date and End Date filters to track daily, weekly, monthly, or yearly performance.

📦 Product Sale Report workflow

Go to Sale → Menu Reporting → Click on "Product Sale Report" to open the view.
Only authorized sales users can access the product sales report, whereas administrative menus are restricted to administrators; other users cannot access them.

Report Type: Sale - Add the required details, select the category, choose the Sale type, and download the report by clicking on "Product Sale Report".

Report Type: Sale - Displays detailed information including product name, quantity sold, on-hand quantity, total number of products, and total quantity.

Go to Point of Sale → Menu Reporting → Click on "Product Sale Report" to open the view.
Only authorized Point of Sale users can access the product sales report, whereas administrative menus are restricted to administrators; other users cannot access them.

Report Type: Point of Sale - Add the required details, select the category, choose the Point of Sale type, and download the report by clicking on "Product Sale Report".

Report Type: Point of Sale - Displays detailed information including product name, quantity sold, on-hand quantity, total number of products, and total quantity.

Report Type: Both - Add the required details, select the category, choose the Both type, and download the report by clicking on "Product Sale Report".

Report Type: Both - Displays detailed information including product name, quantity sold, on-hand quantity, total number of products, and total quantity.

What does this module do? +

This module generates product-wise sales reports using data from Sales Orders, Point of Sale (POS), or both, with flexible filtering options.

Which Odoo applications are supported? +

The module works with: Sales, Point of Sale (POS)

Can I generate reports from Sales Orders only? +

Yes, Select Sales as the Report Type to generate reports using only Sales Order data.

Can I generate reports from POS only? +

Yes, Select Point of Sale as the Report Type to generate reports using only POS Order data.

Can I combine Sales and POS data in one report? +

Yes, Select Both as the Report Type to include Sales Orders and POS Orders in a single report
